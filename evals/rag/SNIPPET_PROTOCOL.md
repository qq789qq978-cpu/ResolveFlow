# 2.3 片段引用评测补充

2.2的标签、45/35集合、原协议和baseline.json全部保持不变。2.3修改引用与业务处理边界，不修改BM25。最终实现确定后运行一次80条评测，只查看保留集汇总；不按保留集逐题结果调优。

新增metric_schema=2：reference_validity允许实际返回的文档或片段ID，verbatim_quote_validity检查被引用片段内的逐字摘录；分母为0仍为null。旧document_citation_validity严格保留“文档ID引用”的含义，新代码只用片段ID，其值0不代表片段失效。跨版本比较引用存在性应使用2.2的document_citation_validity和2.3的reference_validity，并披露表示方式变化。chunk_citation_rate、证据召回和查询证据覆盖口径不变。

demo变为保守的业务请求分流，仅明确请求退款/查询物流状态且检索到对应规则整段时提出可处理建议；其他政策问答交人工。严格的引用结构不等于实现了开放域政策问答，可能增加可答问题的转人工比例和降低查询证据覆盖，必须如实记录。不要把“所有问题转人工”当作质量提升。

引用校验只证明来源和摘录一致，不验证模型自由reason的语义蕴含。页面最终答复使用确定性退款规则或订单状态模板；模型原reason仅保留在调查快照供审计，不能作为已核准答复。部分/无依据、未知片段、旧文档ID、失配原文均不能授权退款。真实模型质量仍为not_measured，留到2.11。
