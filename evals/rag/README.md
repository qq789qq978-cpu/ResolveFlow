## 标注契约

`cases.v1.json` 是标注唯一来源，`CASES.md` 是校验通过后生成的阅读视图。2.2后该v1快照已冻结，修改标注应新建版本并复核划分。每条包含稳定编号、查询、类别、辅助标签、近义/模板分组、预期证据、回答边界、不得声称的内容，以及来源和复核状态。

|字段|含义|
|---|---|
|corpus|3份文档的id、标题、版本、路径、SHA-256及整个清单的指纹|
|evidence_catalog|R1–R3退款、S1–S2物流、U1–U2核查；逐段记录原文、行号、chunk_id、版本和文档SHA|
|expected.answerability|`supported`有直接依据；`partial`只能答部分；`unsupported`领域内缺少所问依据；`out_of_scope`范围外/噪声|
|required_evidence_groups|组间为“且”，组内为“或”。如`[["R1"],["U1"]]`要求两段；`[["R1","S1"]]`接受任意一段。直接/部分可答必须非空|
|optional_evidence|有帮助但不作为必要命中的补充片段|
|guardrail_evidence|可以解释限制或转人工的上下文，**不能当作对所问事实的直接答案证据**|
|answer_outline|参考回答边界，用于后续支持性评测，不是必须逐字匹配的生成答案|
|must_not_claim|原文不能支持或与原文冲突的具体说法|
|annotation.basis_evidence|所需与可选答案证据的并集；通用限制说明单列在guardrail_evidence|
|annotation.absence_checked_against|部分可答/无法回答时，声明仅在本次3份冻结文档范围内检查缺失，不声称世界上没有该政策|
|annotation.*review*|同一模型自查、人工待复核、未独立复核；结构校验不能升级这些状态|
|leakage_group|53个初步语义/模板分组，22组包含多个样例；供2.2防止近义题跨集合泄漏，不是已经划好的数据集|

例如RAG-063询问真实退款到账时效：R3能说明这里只记录模拟退款，但不能给出到账天数。因此它是“政策缺口”，直接答案证据为空，R3只列入限制说明。检索到R3不代表问题已有答案，也不必一概判为无关噪声；2.2须分别定义检索相关性和答案支持性，不把“没有直接答案”简单等同“必须返回空列表”。

RAG-053询问当前文档版本，依据可以是任一退款片段的返回元数据；version=2只说明当前收录字段，不证明生效日期或业务审核状态。RAG-054/056/057/058/059分别保留能回答的部分和无法支持的历史/日期/有效性结论。

政策性问题按其假设回答，不据用户自述认定真实订单事实；候选答案不能授权退款。文档中“自动”指项目的确定性规则和模拟台账，不是RAG或模型可以直接操作真实资金。

## 校验与维护

在仓库根目录，使用项目Python环境（读取文档需要PyYAML，无需数据库或模型配置）：

```powershell
python scripts/validate_rag_dataset.py --report validation/rag-candidates-check.json
python scripts/validate_rag_dataset.py --review-md evals/rag/CASES.md
python -m pytest test_rag_dataset.py -q
```

报告路径必须未存在；阅读视图可以重新生成。校验器检查80条数量、分类、重复ID/归一化重复查询、证据引用、原文/行号/版本/文档指纹、答案类型一致性、来源字段及当前复核状态，**不调用排序器、不连接数据库、不请求模型，不证明语义标注必然正确**。

文档指纹与现有 `rag.read_documents` 一致：UTF-8读取后使用统一换行的文本计算SHA；整个语料指纹为排序键的紧凑JSON文档清单SHA。跨Windows/Linux换行转换不改变这些语料指纹。

如果知识库改变，校验器应报告语料漂移。需要逐条核对受影响标签并记录修订/新数据版本，不能仅替换指纹掩盖语义变化。当前v1契约固定为模型候选标签；真正完成人工/独立复核时，应扩充版本化审查记录（复核人、日期、依据和改动），再更新验证契约，不能简单把pending改成approved。

`evaluate_rag.py` 的12条公开冒烟查询仍保持原样，既有 `eval_cases.json` 含历史refund-v1样例，不作为本集政策来源。80条全部采用新查询措辞、未根据检索结果挑选。2.2已审查跨组近似问题和三份公开评测文件的34条查询，将原53组合并为37个意图族，公开题相关族归调优；详见划分与协议。保留集只展示汇总，后续只能用调优集逐题结果定位问题，不能把共享语料和同一模型标注宣称为外部独立数据。
